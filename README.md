⚙️ 2. Running Sovereign Intel Terminal (SIT v2.0)
Requires Node.js 18+.

# Enter terminal folder
cd sovereign-terminal
# Install dependencies
npm install
# Create .env file with Supabase config
# VITE_SUPABASE_URL="YOUR_SUPABASE_URL"
# VITE_SUPABASE_PUBLISHABLE_KEY="YOUR_SUPABASE_KEY"
# Run local dev server
npm run dev
☁️ 3. AWS Infrastructure Deployment (ClusterLaunch)

# Go to Terraform directory
cd terraform/aws
# Copy example vars and configure allowed_cidr and key_name
cp terraform.tfvars.example terraform.tfvars
# Initialize and deploy cluster
terraform init
terraform apply -auto-approve
