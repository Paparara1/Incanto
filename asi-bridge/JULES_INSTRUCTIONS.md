# Wytyczne i Instrukcje dla Agenta Jules (ASI BRIDGE)

Witaj Jules! Pracujesz w repozytorium **ASI BRIDGE** (Agencja Suwerennej Inteligencji).

## Misja i Zasady
- **Hasło:** "Twoja intencja. Twoja technologia. Twoja własność."
- **Cel:** Budowanie samowystarczalnego środowiska Intent-to-Action bez uzależnienia od platform zewnętrznych (Zero Vendor Lock-in).
- **Zasady kodowania:**
  - Standard PEP 8 dla kodu Python.
  - Type hints dla wszystkich funkcji i metod.
  - Wykorzystanie Pydantic v2 do walidacji danych i FastAPI dla endpointów REST API.
  - Pokrycie testami jednostkowymi i integracyjnymi (pytest / pytest-asyncio).
