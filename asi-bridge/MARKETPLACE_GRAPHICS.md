# Marketplace Graphics

This directory contains SVG placeholder graphics for the GitHub Marketplace listing. You can export the SVGs to PNG (recommended sizes below) or replace them with high‑quality PNG/PNG exports.

Files provided
- asi-bridge/assets/icon.svg — square icon (128x128) for Marketplace. Export to PNG 128x128.
- asi-bridge/assets/screenshot-architecture.svg — architecture diagram. Export to PNG 1280x640.
- asi-bridge/assets/screenshot-demo.svg — demo UI mockup. Export to PNG 1280x640.

Recommended export settings
- Format: PNG (lossless) or JPEG (web optimized) where required.
- Icon: 128x128 px PNG, transparent background preferred.
- Screenshots: 1280x640 px PNG, sRGB color profile.

How to replace with custom graphics
1. Create your PNG/JPEG files with the recommended dimensions.
2. Upload them to the repository or the Marketplace UI during publication.
3. Update the filenames in this directory or reference them directly in the Marketplace form.
